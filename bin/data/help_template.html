📖 使用帮助 · 快速了解如何使用本工具

基本操作

  • 在输入框中输入内容，按回车键执行
  • 支持实时搜索和快捷启动
  • 双击列表项可执行对应操作

快捷命令

  • help - 显示此帮助信息
  • set - 显示设置菜单
  • js - 切换到计算模式
  • wz - 切换到网址收藏模式
  • dir - 切换到目录浏览模式
  • q - 退出现有模式

模式说明

  • 设置模式 (set)：显示设置菜单，可以管理网址收藏、退出程序等
  • 计算模式 (js)：输入数学表达式进行计算，支持常用数学函数
  • 网址收藏模式 (wz)：浏览和管理收藏的网址，支持搜索和快速打开
  • 目录浏览模式 (dir)：浏览文件和文件夹，支持展开目录和打开文件

使用技巧

  • 使用 Ctrl+Alt+Q 快速显示/隐藏窗口
  • 最小化窗口时会自动隐藏到系统托盘
  • 支持模糊搜索，输入部分名称即可匹配
  • 在目录浏览模式下，点击目录可展开，双击文件可打开
💡 提示：输入任意内容开始搜索，或使用上述命令进入特定模式
