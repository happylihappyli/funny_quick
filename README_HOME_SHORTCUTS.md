# 首页快捷方式功能

## 功能介绍

首页快捷方式功能允许用户在程序启动时快速访问常用的快捷方式，类似Windows的开始菜单。

## 使用方法

### 1. 添加快捷方式并设置显示在首页

1. 按下 `Ctrl+Alt+Q` 显示程序窗口
2. 输入 `add` 并按回车键，打开添加快捷方式对话框
3. 填写快捷方式名称、路径和备注
4. 勾选「显示在首页」复选框
5. 点击「确定」按钮

### 2. 编辑快捷方式的显示设置

1. 按下 `Ctrl+Alt+Q` 显示程序窗口
2. 找到要编辑的快捷方式
3. 右键点击快捷方式，选择「编辑」
4. 在编辑对话框中，勾选或取消「显示在首页」复选框
5. 点击「确定」按钮

### 3. 首页快捷方式的显示

当程序启动时，如果有快捷方式被标记为「显示在首页」，程序将自动显示首页快捷方式页面，展示所有标记的快捷方式。

用户可以点击首页上的快捷方式图标，直接打开对应的程序、文件夹或网址。

## 技术实现

### 数据结构

在 `common.h` 中，`ShortcutItem` 结构体添加了 `showOnHome` 字段：

```cpp
struct ShortcutItem {
    WCHAR name[256];
    WCHAR path[256];
    WCHAR comment[512]; // 备注信息
    WCHAR iconPath[512]; // 图标路径
    int type; // 0 = directory, 1 = URL, 2 = application
    int usageCount;
    bool showOnHome; // 是否在首页显示
};
```

### 存储格式

快捷方式文件 `data/shortcuts.txt` 的格式更新为：

```
名称|路径|类型|备注|图标路径|使用次数|显示在首页
```

其中「显示在首页」字段为 `1`（显示）或 `0`（不显示）。

### 界面实现

首页快捷方式页面使用WebView2实现，采用响应式网格布局，支持鼠标点击打开快捷方式。

## 快捷键

- `Ctrl+Alt+Q`：显示/隐藏程序窗口
- `F3`：编辑当前选中的快捷方式
- `Delete`：删除当前选中的快捷方式
- `Tab`：在编辑框和列表框之间切换焦点
