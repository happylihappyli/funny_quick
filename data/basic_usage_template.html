🚀 Funny Quick 快速入门

📋 基本功能

  • 快速搜索和启动应用程序
  • 支持模糊搜索和快捷键操作
  • 智能推荐和历史记录
  • 自定义快捷方式和分类

⌨️ 快捷键操作

1按 Ctrl + Space 打开搜索窗口
2输入应用名称或关键词进行搜索
3使用方向键选择目标应用
4按 Enter 启动应用或 Esc 取消

🔍 搜索技巧

  • 输入应用名称的部分字符即可匹配
  • 支持中文和英文搜索
  • 支持路径搜索，查找包含特定路径的程序
  • 使用上方向键查看搜索历史

📁 文件模式

1输入 file 或 文件 进入文件模式
2在文件模式下，可以快速搜索和浏览系统文件
3支持文件名搜索、路径搜索和文件类型过滤
4输入 q 退出文件模式

💡 使用提示

  • 双击搜索结果可以直接启动应用
  • 右键点击可以进行更多操作

  • 定期更新可获得更好的体验
